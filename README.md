# Adv-CS---Data-Science
**Learning Data Science to Analyze Music Trends**
This project is for me to learn a new skill in analyzing and visualizing data using python. This repository will contain an ipynb file for google collab that will act as a way of tracking my progress. It will not only contain notes but also three key milestone projects that are created along the way. Most learning will be done using the Associates Data Science course from data camp, with the final project combining all of the teachings into a project that analyzes and communicates music trends observed across communities. 

The file Milestone_2_Customer_Analytics contains the second milestone project's code. It is a ipynb file that walks the user through an analysis and visualization of a dataset and the thought process behind it. For functionality, the first cell must always be run so all libraries and data is imported, however afterwards, not everything needs to be run. This specific project followed four basic steps: analysis of data, converting data (int,bool,float,nominal), converting data (ordinal), and filtering data. Each step is seperated into different sections with multiple cells, walking through the logic behind each piece of code. 

Milestone_3_Coffe_Quality_analysis contains the code to the third milestone. It is also an ipynb file which walks the user through the exploration and visualization of data when it comes to coffee quality. The file has 4 sections, the importing of packages and data, in which the data used was downloaded from kaggle and linked from github. The second section is the cleaning and exploration of the data. the third sections contains the actual visualization, spread out into specific subsections, and the final section contains the conclusions of this project. It should be noted that much of the data involving the scores associated with each coffee is done by a human and not rooted in quantitative data, it is merely a number associated with the graders perception of a given cup, and as that is subjective this data is not going to be definitive for everything. In addition, this data is limited to around 1500 unique values, which is not a lot when we consider the sheer amount of different farms, producers, varieties that cofee has, the conclusions drawn in this file should only serve as an entry point into coffee research rather than providing concrete answers.
